## Convenções de colunas

1. **REQ PDF (1 a 17)**: correspondência 1:1 com os 17 grupos de requisitos do PDF de spec (domínio, LangGraph, Tool, Memória, Segurança, Observabilidade 2 sinais, QA IA code review, Pipeline lint/test/build, Logs IA analisa pipeline, Anomalia, Tendência risco, Low-code n8n, Sugestões documentadas, Refinamento prompts, README + /docs + vídeo, Explicação técnica, Demonstrabilidade).
2. **Implementação**: sempre no formato `caminho/arquivo.ext#Lx-Ly` com linhas reais do código.
3. **Teste associado**: aponta arquivo de teste e, quando possível, linha.
4. **Evidência**: arquivo/documento/endpoint com a prova tangível.

## Notas de atualização

- Sempre que uma nova feature for adicionada, adicionar linha nova **no final** com número > 17, não reutilizar 1-17.
- Se uma implementação for movida de arquivo, atualizar a referência `#Lx-Ly` nesta matriz.
